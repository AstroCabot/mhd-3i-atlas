# CCMC benchmark movie

The benchmark uses native 3-D output from [CCMC run Jan_Deca_120925_SH_1](https://ccmc.gsfc.nasa.gov/ror/results/viewrun.php?runnumber=Jan_Deca_120925_SH_1), WSA 5.4 / ENLIL 2.8f. It is rendered alongside the three reconstructions with the same geometric-UTC interval (27 November 2025 06:00 to 5 December 00:00), J2000 ecliptic x/y projection, ±2.4 AU axes, fixed Inferno colour map, and flux/flux-times-radius-squared limits. Both MP4 exports are 768² pixels, 30 fps and 48 seconds. The portable player uses the same 373 half-hour display epochs, persistent image layers and controls for all four fields.

`scripts/prepare_ccmc_movie.py` reuses eight previously archived volumes and obtains the 25 missing volumes through the public CCMC file API. The required 33 volumes are `tim.0228.nc` through `tim.0260.nc`, including support on both sides of the displayed interval. Their actual timestamps are used, including the few-minute variation around nominal six-hour outputs. There is no extrapolation. Original research inputs remain read-only; fetched volumes and compact flux arrays are stored in application-owned runtime storage.

The source grid has 576 radial, 24 colatitude and 90 longitude cells. Block 0 is the CME calculation with the run's 64-entry cone catalogue; block 1 is the ambient control and is excluded from this movie. The native grid extends from 0.1 to 3.1 AU. The common displayed Cartesian axes do not create additional native spatial resolution or force identical radial support between different models.

For every native cell, proton density is `D / mp / (1 + 4*xalpha)`, with `xalpha = 0.05` and the native export convention `mp = 1.67239e-27 kg`. Conversion is applied once. The flux is proton density times the full speed `sqrt(V1² + V2² + V3²)`, with SI units converted to cm⁻² s⁻¹. This matches the heliocentric total-speed definition used by Argon and Codex; Claude's retained slice supplies the radial proxy instead.

At each native epoch, the Earth-anchored HEEQ+180 grid is rotated into the fixed J2000 solar-pole basis. The ecliptic plane is then sampled trilinearly with periodic longitude. The display ephemerides and the archived virtual-probe ephemerides differ slightly: the largest checked longitude difference is about 0.13°, and latitude about 0.057°, compared with the native 4° angular cells. Radius differences are recorded separately. A spacecraft's archived trajectory is used when checking native interpolation; it is not silently replaced with a different ephemeris.

The published [verification receipt](https://astrocabot.github.io/mhd-3i-atlas/data/ccmc-movie-provenance.json) records source URLs, native volume sizes and SHA-256 hashes, compact-input hashes, coordinate inputs and checks, and primitive-field comparisons at Earth, STEREO-A and the comet. A separate regression test reconstructs the coordinate basis and physical flux directly from an original volume to detect a longitude sign/180° error, a double helium correction, an incorrect velocity magnitude or a unit conversion error.

Physical flux is interpolated between native six-hour states before logarithmic colour mapping. Browser interpolation adds visual continuity between half-hour display images. Neither the 30 fps export nor the half-hour display support adds native temporal information. This external reconstruction is a comparison model; its agreement with another reconstruction is not a measurement of the plasma at the comet. The NASA comparison section retains the spacecraft residuals, calibration context and model limitations.
