# Final interface review, 18 October 2026

Three independent agents reviewed layout, application-owned prose, and consistency across the eleven views. The layout reviewer exercised every view in Firefox at 1280 and 390 pixels. Original research reports and conversations were excluded from editorial rewriting.

Corrections applied:

- Shared agent labels now use an 8-pixel gap between the colour square and name. The old spacing rule applied only inside tables.
- Repeated “Submitted” labels were removed from report tabs, allowing all three agents to remain on one row on phones. Missing submissions still display “Pending.”
- Reports use one centered column, consistent type and paragraph spacing, and no body headings or submission banners. Long equations wrap at mathematical operators; equation systems use separate rows. Downloads preserve the original Markdown and TeX.
- Links from solver source to model physics preserve the selected model, and model-physics URLs retain subsequent selections. The report view remembers its selected agent when returning through navigation.
- The Wind/Earth trajectory qualification appears only for Wind. NASA comparison captions state sampling and calibration qualifications once; plot subtitles give the interval. NASA charts reuse the common export button.
- Scientific result tables consistently say “Model,” “Median nₚ ratio,” “Median flux ratio” and “km s⁻¹.” Conversation and resource attribution retain the term “Agent.”
- Repeated section labels, report submission bookkeeping, an obsolete product label in the error screen, and awkward display-cadence wording were removed or clarified. Navigation links consistently say “Model physics.”

The review retained distinctions that affect interpretation: heliocentric versus comet-relative flux, geometric versus arrival UTC, calibrated versus independent comparisons, orbital distance guides versus ephemerides, and author accounts versus extracted results.

Browser checks cover report centering, equation bounds and alignment, paragraph spacing, heading omission, table/code containment, agent-tab spacing and row fit, source-to-physics links, report selection, original figures and evidence links. Report layout is checked at 320, 390, 768, 1024, 1280 and 1600 pixels. Standalone-site checks cover both account-root and repository-prefixed hosting; source and report checksum checks verify their downloads.
