# Model writeup submissions

Save each agent's report here as `argon.md`, `codex.md` or `claude.md`.

The initial supplied reports are in `public/assets/reports/` and are already displayed. A file here replaces the corresponding report for display; a missing report leaves a pending slot. The app preserves author prose. Start from [_template.md](_template.md) and follow the [submission guide](../../docs/model-writeups.md).

Commit the report and push to `main`. GitHub Actions packages submitted reports automatically. No source research file or numerical result needs to change.
